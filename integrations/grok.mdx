Whappy is added to Grok on grok.com as a **custom connector**. xAI says connectors are available to all Grok users. On Grok Business and Enterprise, a team admin first has to set the connector up for the team in xAI's console.

For what a connection can do, its limits and the data it sees, read [MCP connectors](/integrations/mcp).

## Add Whappy

<Steps>
  <Step title="Open Connectors">
    Go to [grok.com/connectors](https://grok.com/connectors).
  </Step>
  <Step title="Add a custom connector">
    Click **New Connector**, then **Custom**. Enter this URL:

    ```
    https://mcp.whappy.ai/mcp
    ```
  </Step>
  <Step title="Sign in">
    Complete the sign-in Grok asks for: sign in to Whappy and click **Allow**.
  </Step>
</Steps>

<Warning>
  xAI's page does not say how Grok signs in to a custom connector, and we have not yet tested Whappy in Grok end to end. If Grok asks for a token instead of opening a Whappy sign-in page, give it a [personal access token](/integrations/mcp#personal-access-tokens), and [tell us](/support/contact-support) what Grok showed.
</Warning>

Grok does not document asking you before an action, so a request like "delete the old funnel steps" may run without a confirmation. Be precise in what you ask.

## The xAI API

The xAI API's remote MCP tool sends a fixed token instead of signing in. Create a [personal access token](/integrations/mcp#personal-access-tokens) on the [MCP connectors](https://app.whappy.ai/integrations/ai-assistants) page, then give the API the server URL `https://mcp.whappy.ai/mcp` with the token sent as the header `Authorization: Bearer <your token>`.

The token can do what an OAuth connection can, and messages your contacts only if you ticked **Allow it to act in my chats** when you created it.

## Disconnect

Remove the connector in Grok's **Connectors** page. To be sure the access is cut off on Whappy's side, click **Revoke** next to it (or next to the personal access token) in **Connected apps** on the [MCP connectors](https://app.whappy.ai/integrations/ai-assistants) page.
