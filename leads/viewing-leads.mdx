Every campaign has a **Leads** tab listing everyone in it, what state their conversation is in, and whether they have an appointment booked.

## The table

| Column | What it shows |
| --- | --- |
| **Name** | The lead's name. |
| **Phone number** | In full international format. |
| **Email** | If you have one; otherwise *N/A*. |
| **Conversation** | The state, and how many messages have been exchanged. |
| **Appointment** | The booking, if one was made. |

## Conversation states

| State | Meaning |
| --- | --- |
| **Ready** | In the campaign, no message sent yet. |
| **Started** | The first message has gone out. |
| **Active** | A conversation is under way. |
| **Qualified** | The lead answered everything you asked for. |
| **Error** | Something went wrong on this conversation. |

## Searching and filtering

**Search** matches leads by name, phone or email.

**Filters** narrows the list by:

- **Conversation state** — any of the states above, or all of them.
- **Date range** — a *from* and a *to* date.

The current filters are summarised above the table, and **Clear all** removes them in one go.

## Looking at one lead

Each row's actions menu offers:

- **View conversation** — the full message history. See [Conversation history](/leads/conversation-history).
- **View lead info** — every answer collected from this lead.
- **Delete lead**.

## Exporting

**Export to CSV** downloads the leads currently listed, including the information collected from them.

<Note>
    Phone numbers must include a country code. Whappy flags a number missing one and suggests the corrected form, because a number without a country code cannot be messaged.
</Note>
