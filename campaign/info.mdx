**Info** lists the details your assistant collects from each lead during the conversation: a budget, a timeline, a project type. Each one is a field. A funnel step asks for it, and the answer is saved on the lead.

A [campaign for existing customers](/campaign/client-campaigns) has no Info page: the questions come from each offer.

## How it works

1. **Create a field** for each thing you want to know.
2. **Add an Ask information step** to your [funnel](/campaign/funnel) and pick the field.
3. **The assistant asks for it** in its own words during the conversation.
4. **Read the answers** under **View lead info** on the lead. See [Viewing leads](/leads/viewing-leads).

## Adding a field

There are two ways:

- **Generate with AI**: describe what the assistant should find out, in a sentence. Whappy creates the field from it.
- **Add manually**: fill in the field yourself.

A field has:

| Setting | What it is |
| --- | --- |
| **Field title** | The name you see in the table, the funnel and the lead's details. For example `Budget`. |
| **Description** | What the assistant should ask for. For example *Ask about the client's budget for this project*. |
| **Information type** | **Text**, **Number** or **Multiple choice**. |
| **Example questions** | Optional. Ways of asking that guide the assistant. |
| **This information is required** | Whether the assistant keeps asking until it gets an answer. |

The fields are listed in a table with their **Title**, **Description**, **Type** and **Required**, and an edit and a delete button.

## Information types

### Text
Open answers: a description of the project, the biggest challenge, a website address.

### Number
Numeric answers: a budget, a number of employees. A [Condition](/campaign/funnel#condition) step can compare it with greater than, less than and so on.

### Multiple choice
A fixed set of options. Each option has:

- **Option key**: used internally, for example `small_budget`.
- **Explanation**: the text shown to users, for example *Under $5,000*.

A multiple-choice field needs at least one option, and every option needs both a key and an explanation.

**Example: Budget range**
- `small_budget`: Under $5,000
- `medium_budget`: $5,000 to $15,000
- `large_budget`: Over $15,000

## Required and optional

- **Required**: if the lead does not answer, the assistant asks again until it gets an answer.
- **Optional**: the assistant asks once and moves on.

## Deleting a field

A field used by a step in the funnel cannot be deleted: the button says *Cannot delete: info is used in funnel.* Remove it from the funnel first.

When you delete a field, the assistant stops asking for it. Answers already collected stay on the leads.

## Example fields

| Business | Fields |
| --- | --- |
| **Web design agency** | Project type (Multiple choice), Budget range (Multiple choice), Timeline (Text) |
| **Business consultant** | Company size (Number), Annual revenue (Multiple choice), Main challenge (Text) |
| **Real estate agent** | Budget range (Multiple choice), Home type (Multiple choice), Location preference (Text) |

<Tip>
    Start with three to five fields. Each one is a question your lead has to answer.
</Tip>
