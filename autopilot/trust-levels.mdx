The **Assistant** is the chat panel in the dashboard. It answers questions about your campaigns, leads and billing, and makes changes for you when you ask.

## No permission levels

Earlier versions of Whappy had five permission levels for the Assistant (Read only, Draft, Build, Launch, Operate) and asked you to earn the top two. **These levels no longer limit anything.** The Assistant can do whatever you ask it to, at any level, and the settings screen for the levels is no longer linked from the dashboard.

What still applies are the limits below and the record of every change.

## Limits that still apply

| Limit | What it covers |
| --- | --- |
| **3 in any 7 days** | Actions that can start messaging people: switching a campaign on or off, starting a conversation with a lead, sending a message or a template to a lead. |
| **30 AI generation requests per hour** | Building a campaign, generating a funnel, context or questions, and running a rehearsal. |

When a limit is reached, the Assistant tells you which one and asks you to try again later. Only actions that succeeded count towards a limit.

These limits apply to the Assistant only. Anything you do yourself in the dashboard is not counted.

## The record of changes

Whappy records every change the Assistant makes, and every AI generation it runs.

- **Only changes are recorded.** Reading your data is not.
- **Values are never stored.** The record keeps the name of the action and the names of the fields involved, never their contents. Your leads' phone numbers, message bodies and API keys pass through these actions; the record does not keep a copy of them.
- **Refused actions are recorded too**, with the reason, for example a limit that was reached.

## Coach's automatic mode

Letting Coach change a campaign's wording by itself is a separate setting on each campaign, not an Assistant permission. Only you can switch it on. See [Coach](/autopilot/coach#the-three-modes).
